# Programming Languages
- Languages that *helps to communicate  with computers* (Humans are not able to understand it)
- Help us to write program using the languages
## Program
- An *algorithm expressed in the programming languages*.
    - **Algorithm**: Detailed *sequence of actions to perform a certain tasks*
        - Named after *Iranian* mathematician **AL-Khwarizmi**
        - To reach a result it must pass through a finite sequence of steps
        - As a result of those sequences programs to a specific tasks
### Pseudocode
- *Simplified, structures way of writing down program logic in a plain languages*, without being concerned about the syntax of the programming languages
- *Uses short, clear statement to define each step of the logic of program*
    - For beginners: easy to understand how algorithm works
    - For programmers: to plan complex solution before writing an actual code
- Main concern: breaking down of a processes
## Evolution of I/O(input and output)
- Early history computing
    - Programs used to be **submitted on punch card** with all the required data
    - The required and executed together with other programs that used the same libraries
    - Output was on line printer
- Later development
    - **Interactive processing**
    - Allows users to provide data while the program was running
    - Takes place as in question and answer format
## Generation of Computers
1. *First generation*: Vacuum Tubes, Punch card
2. *Second generation*: Transistors, programming started in assembly
3. *Third generation*: Integrated Capacitors. Basic, COBOL, Pascal, C, C++,Perl
4. *Fourth generation*: Microprocessors(More like CPU). Python, MYSQL, MATLAB
5. *Fifth generation*: Artificial Intelligence 
## Types of Programming Languages
- Computers understand only binaries(0/1)
- Based on closeness of the language to humans and hardware, they're classified into 2
    - The more  the *low like machine the more they're faster* because they're close to the hardware
    - The more the *high like humans the more it's slower* because they're far from the hardware
1. **Low level programming languages**
    - More **close to the machine/hardware** but require lots of knowledge to be understood by humans
    - Assemble, C-language
2. **High level programming language**
    - More **close to human language**
    - Python, C++, JS, java
    #### How does HLL work?
    1. Complier: Tool that helps to convert whole code/ source code to bytecode then computer will execute it
        - C, C++, java
    2. Interpreter: Directly execute the code by reading the source code line by line
         - Python

# Python
- High level and interpreted language
- Easy to learn and understand
- **History**: *Guido van Rossum* developed python in the late 80's and early 90's
    -  Python derived from *many other languages(ABC, Modula-3, C, C++, Algol-68, Smalltalk, UNIX shell and other script lang)*
- **Uses**: *Data visualization and analysis, ML, AI, Backend framework (Django, flask), Game development and hacking scripts* 
- **IDE(Integrated Development Environment)**
    - Software that helps to write and run a *specific programming languages*
    - eg: python IDE
- **Code Editors**
    - Software can help to write *any kind of programming languages*, also by *adding some compiling/ interpreting feature* they can run programs
    - eg: Sublime, VScode
